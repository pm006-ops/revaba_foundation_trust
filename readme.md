# Revaba Charitable Foundation Trust

Official website for **Revaba Charitable Foundation Trust**, a non-profit organization dedicated to social welfare, education, environmental conservation, healthcare, and community development.

---

## About

This project is a responsive one-page website built to present the Foundation's mission, activities, trustees, and contact information in a modern and accessible format.

The website is designed with simplicity, responsiveness, and accessibility in mind.

---

## Features

- Responsive Design
- Mobile Navigation
- Smooth Scrolling
- Dark Mode
- Social Media Integration
- Contact Information
- Professional Foundation Layout

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome Icons
